# NCCM · Nueva Creación

Web app en modo aplicación para el proyecto **NCCM**, entregada por Kingdom Vizion Studio.

## Abrir

Abre `nccm/index.html` en el navegador, o sirve la carpeta:

```bash
python3 -m http.server 8000
# luego visita http://localhost:8000/nccm/
```

## Contenido

- Splash de marca
- Inicio con hero a pantalla completa
- Horarios, ministerios y eventos
- Navegación inferior tipo app
- Enlaces a WhatsApp y correo del estudio
- `manifest.webmanifest` para instalación PWA básica

Los textos de horarios/eventos son plantilla editable para el cliente final.
